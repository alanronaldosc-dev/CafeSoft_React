# HU-016 - Liquidación de repartidor

Se agregó el módulo `Liquidación de Repartidores` al menú web.

Permite:
- Seleccionar repartidor y fecha.
- Ver efectivo, transferencias, garrafones entregados y carga inicial.
- Registrar garrafones no vendidos devueltos.
- Registrar efectivo entregado por el repartidor.
- Calcular diferencias automáticamente.
- Registrar el cierre como `CONFORME` o `DIFERENCIA REGISTRADA`.
